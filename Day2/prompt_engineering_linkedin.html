Prompt Engineering: A Visual Guide

Prompt Engineering

The skill of talking to AI so it actually listens

What is it?

Prompt engineering is the practice of crafting your inputs to an AI model in a structured, intentional way — so you get precise, useful, and consistent outputs instead of vague or generic ones.

Normal vs. Engineered prompt

Normal prompt

"Write me a marketing email."

Vague → generic AI filler

Engineered prompt

"Write a 150-word email for a SaaS product targeting HR managers. Tone: friendly & direct. Include a CTA to book a demo."

Specific → targeted result

5 core techniques

1

Role assignment

"Act as a senior data scientist..." — giving a persona sharpens tone, depth, and vocabulary.

2

Context + constraints

State the audience, format, word count, and what to avoid. Constraints = fewer surprises.

3

Chain-of-thought

"Think step by step before answering." Forces the model to reason before responding.

4

Few-shot examples

Show 2–3 example input/output pairs so the model mirrors your desired style exactly.

5

Output format specification

"Return as a JSON object with keys: title, summary, tags." Eliminates reformatting work.

Tips by AI tool

Claude

Use XML tags like <task> and <context>. Claude follows nested structure very well.

ChatGPT

Leverage the system message for persistent persona & rules across the conversation.

Gemini

Works well with multimodal context — pair your text prompt with images for richer outputs.

Copilot

Reference specific files or code blocks directly. Context-grounding improves accuracy.

Midjourney

Use style suffixes like "--style raw" and weight tokens like "sunset::2 city::1" for control.

All tools

Iterate! Treat your first prompt as a draft — refine based on what the output reveals.

Golden rule: The more precise your input, the more useful the output. Treat every prompt as a brief to a smart but context-free collaborator.
