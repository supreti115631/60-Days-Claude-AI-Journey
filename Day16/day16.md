# Custom Skills & Automation  

Today's focus: Learn how to create reusable Custom Skills in Claude.

Most users repeatedly paste the same prompts every time they want a task completed. Power users create Custom Skills so Claude automatically follows a predefined workflow without requiring the prompt to be pasted again.

Today you'll build a professional Stock Fundamental Research Skill that can analyze Indian and global listed companies using financial statements, valuation metrics, business quality, management analysis, risks, competitive advantages, ownership patterns, and growth prospects.

Once the skill is created, you can reuse it indefinitely without rewriting the prompt.

Tasks:

Learn how Custom Skills work.
Create your first Stock Research Skill.
Configure instructions and behavior.
Test the skill on multiple stocks.
Generate research reports and comparisons.
Share your learning publicly.
Important: Set Claude's effort level to Low before creating the skill.

The goal is to learn reusable workflows. After the skill is created, you only need to mention the stock name and Claude will automatically follow the instructions.
